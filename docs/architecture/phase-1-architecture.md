# 第一阶段架构说明

## 决策摘要

采用“模块化单体 + 分层架构”，不引入微服务或重量级 Agent 框架。桌面应用的部署单元保持单一，但解析、检索、模型、导出均通过适配器边界隔离。

## 依赖方向

```text
PySide6 UI
    ↓
Application（用例、任务、Agent 工作流）
    ↓
Domain（实体、值对象、业务规则、端口接口）
    ↑
Infrastructure（SQLite、LLM、Parser、Retriever、Exporter）
```

启动层负责组装依赖，UI 不直接创建数据库会话或调用外部模型。耗时任务将在后续阶段通过工作线程运行。

## 第一阶段边界

- 已实现：启动组装、配置、日志、数据库基础设施、主窗口骨架。
- 已预留：领域、应用、解析器、检索、LLM、导出、Prompt 和 Agent 目录。
- 尚未实现：课程 CRUD、教材解析、模型调用、题目与试卷业务。

## 与课程 P0–P3 文档的衔接

保留阶段交付、AI 人工审查和可追踪设计决策要求。P1/P3 示例中的校园互助领域与本项目不一致，因此后续需求、用例、类图和数据库设计均以 EduExam Agent 为准。
