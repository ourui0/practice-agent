# EduExam Agent 前端样式与交互规范

> 本文档依据当前 PySide6 代码生成。颜色、尺寸、页面结构和交互状态均以代码实际实现为准，不包含尚未落地的设想。

## 1. 设计定位

当前界面采用 Google Material 3 / Google Workspace 风格，视觉重点是冷灰底层、纯白表面、Outlined 表单、药丸导航和克制的卡片悬停反馈。

### 1.1 颜色与层级

| 角色 | 实际颜色 | 代码用途 |
| --- | --- | --- |
| Window Base | `#F8F9FA` | 主窗口、根容器、右侧工作区、弹窗底层 |
| Surface | `#FFFFFF` | 侧边栏、卡片、分组容器、表格、菜单 |
| Outlined Field | `#FFFFFF` | 输入框、下拉框、数值框的内部表面 |
| Primary | `#0B57D0` | 主按钮、输入焦点、滑块、进度条、标签页选中线 |
| Legacy Google Blue | `#1A73E8` | 品牌 Agent 文字、评分徽章、卡片悬停光晕 |
| Primary Text | `#202124` / `#1F1F1F` | 正文与标题 |
| Secondary Text | `#5F6368` | 页面说明、状态和辅助文字 |
| Navigation Text | `#444746` | 未选中导航项与分组标题 |
| Outline | `#E0E3E7` | 卡片、表格、菜单、标签容器边框 |
| Active Pill | `#D3E3FD` | 选中导航项与选择高亮 |
| Hover Blue Surface | `#E8F0FE` | 大纲项、评分徽章及部分交互悬停 |

应用通过 `QPalette` 强制浅色调色板，因此 Windows 使用深色应用模式时，Qt 原生窗口、弹窗和控件仍保持本规范中的浅色外观。

### 1.2 字体与字号

- QApplication 基础字体：`Segoe UI`，`10pt`。
- QSS 字体回退：`Segoe UI`、`Microsoft YaHei`、`PingFang SC`、`sans-serif`。
- 全局正文：`13px`。
- 页面标题：`22px`，字重 `600`。
- 品牌文字：`19px`，字重 `600`。
- 次要说明：`13px`。
- 导航分组标题：`11px`，字重 `600`。
- 评分徽章：`12px`，字重 `600`。

所有现有业务页面的主标题均通过 `pageTitle` 对象名使用统一的 `22px` 样式，不再保留原来的局部 `24px` 标题规则。

## 2. 主窗口结构

- 默认窗口尺寸：`1280 × 800`。
- 最小窗口尺寸：`1040 × 680`。
- 左侧导航固定宽度：`240px`。
- 右侧工作区自适应占据剩余宽度。
- 根布局边距和间距均为 `0`。
- 主工作区背景为静态 `#F8F9FA`，不再绘制全屏鼠标跟随光晕。
- 页面通过 `QStackedWidget` 切换。
- 页面被选中时，如果实现了 `reload_courses()`，主窗口会重新加载该页面的课程数据。

## 3. 左侧 Navigation Drawer

### 3.1 品牌

- `EduExam` 使用 `#444746`。
- `Agent` 使用 `#0B57D0`。
- 品牌字号 `19px`、字重 `600`。
- 侧边栏背景为 `#FFFFFF`，不绘制右侧分隔线，通过白色与主工作区 `#F8F9FA` 的色差划分区域。

### 3.2 信息分组与入口

当前导航实际包含 3 个分组、7 个入口：

1. 核心功能
   - 📚 教材边界
   - 💡 智能推荐
   - 📄 试卷组装
2. 资源管理
   - ✦ 单题生成
   - ▦ 题库与知识点
   - ◇ 课程管理
3. 系统
   - ⚙ 配置与设置

“试卷组装”内部使用“正式试卷 / 训练习题”标签页；“题库与知识点”内部使用“题库 / 知识点”标签页；“配置与设置”内部使用“模型服务 / 系统设置”标签页。原有业务页面没有因导航合并而删除。

### 3.3 导航按钮

- 实现组件：`NavigationButton(QPushButton)`。
- 高度：`40px`。
- 圆角：`20px`，形成完整药丸。
- 外边距：垂直 `4px`、水平 `12px`。
- 水平内边距：`20px`。
- 普通文字：`#444746`，字重 `500`。
- Hover：背景 `#F1F3F4`，文字 `#1F1F1F`。
- Active：背景 `#D3E3FD`，文字 `#041E49`，字重 `600`。
- 鼠标光标：手形指针。
- 状态切换通过动态属性 `active` 和重新 polish 样式实现。
- 当前没有导航药丸的位置插值或缓动动画。

## 4. 表面与卡片

### 4.1 标准表面

`QGroupBox` 和标准卡片使用：

- 背景：`#FFFFFF`。
- 边框：`1px solid #E0E3E7`。
- 圆角：`12px`。
- QGroupBox 内容内边距：上 `20px`、左右 `18px`、下 `16px`。

普通分组容器当前不设置投影，依靠冷白底层、纯白表面和浅边框建立层级。

### 4.2 GlowCard

`GlowCard` 用于智能推荐筛选卡片和推荐题目卡片：

- 默认背景：`#FFFFFF`。
- 默认边框：`1px #E0E3E7`。
- 圆角：`12px`。
- 阴影默认颜色：`QColor(60, 64, 67, 0)`，即完全透明。
- Hover 阴影：模糊半径 `16px`，颜色 `QColor(60, 64, 67, 20)`，偏移 `(0, 2)`。
- 卡片未悬停时既不显示阴影，也不绘制光晕。
- Hover 光晕半径：`160px`。
- 光晕中心：`QColor(11, 87, 208, 12)`。
- 50% 位置：`QColor(11, 87, 208, 4)`。
- 外缘：`QColor(255, 255, 255, 0)`。
- Hover 边框：`#AECBFA`，宽度 `1.2px`。
- 光晕通过圆角 `QPainterPath` 限制在卡片内部。
- Hover 时使用 `24ms` 定时器读取全局鼠标坐标，因此鼠标位于卡片子控件上时光晕仍可跟随。

## 5. 表单控件

### 5.1 Outlined Text Field

`QLineEdit`、`QTextEdit`、`QPlainTextEdit`、`QComboBox`、`QSpinBox` 和 `QDoubleSpinBox` 使用 Outlined 样式：

- 最小内容高度：`22px`，并叠加垂直内边距。
- 背景：`#FFFFFF`。
- 默认边框：`1px solid #DADCE0`。
- 圆角：`8px`。
- 默认内边距：垂直 `10px`、水平 `14px`。
- Hover 边框：`#80868B`。
- Focus 边框：`2px solid #0B57D0`。
- Focus 内边距：垂直 `9px`、水平 `13px`，用于抵消边框增厚并避免尺寸抖动。
- 文本选择背景：`#D3E3FD`。

### 5.2 按钮

- 最小高度：`40px`。
- 水平内边距：`20px`。
- 圆角：`20px`。
- 普通按钮：白色背景、`#0B57D0` 文字、`#C4C7C5` 边框。
- 主按钮：`#0B57D0` 背景、白色文字。
- 主按钮 Hover：`#0842A0`。
- 禁用按钮：`#F1F3F4` 背景、`#9AA0A6` 文字。

## 6. 智能推荐页

- 页面外边距：左、右 `42px`，上 `34px`，下 `30px`。
- 主布局间距：`18px`。
- 顶部筛选区使用 `GlowCard`。
- 筛选卡内边距：水平 `20px`、垂直 `16px`。
- 课程下拉框最小宽度：`180px`。
- 最低综合分滑块范围：`0–100`，默认 `75`，最小宽度 `170px`。
- 目标难度范围：`1–5`，默认 `3`。
- 推荐结果使用无边框、透明背景的滚动卡片流。
- 题目卡片最小高度：`116px`。
- 题目卡片内边距：水平 `20px`、垂直 `16px`。
- 卡片间距：`12px`。
- 题干自动换行并支持鼠标选择复制。
- 右上角 `ScoreBadge` 显示综合推荐分；质量百分比通过 Tooltip 展示。
- 当前卡片表面显示一个综合分徽章，不显示两个并列分数徽章。

## 7. 试卷与训练习题组装页

“正式试卷”和“训练习题”位于同一“试卷组装”导航入口的两个标签页中，并共用同一套分割布局。

### 7.1 Split-pane

- 使用水平 `QSplitter`。
- 左侧：组题条件、题型选择、操作按钮和文本预览。
- 右侧：固定宽度 `320px` 的“试卷结构大纲”。
- 初始尺寸：左侧 `760px`、右侧 `320px`。
- 拉伸权重：`7:3`。
- QSplitter 手柄宽度为 `6px` 且背景透明，不绘制实体分割线。
- 抽屉背景：`#F1F3F4`。
- 抽屉左边框：`1px solid #E0E3E7`。

### 7.2 大纲拖拽

- 大纲使用 `QListWidget`。
- DragDrop 模式：`InternalMove`。
- 默认动作：`MoveAction`。
- 显示拖放位置指示器。
- 每项显示拖拽手柄 `⋮⋮`、序号、题型、分值和题干摘要。
- 大纲项最小高度 `44px`，内边距 `10px`，垂直外边距 `6px`、水平外边距 `12px`。
- 大纲项默认白色背景、`#E0E3E7` 边框、`8px` 圆角。
- Hover 使用 `#E8F0FE` 背景和 `#AECBFA` 边框。
- 选中使用 `#D3E3FD` 背景、`#0B57D0` 边框和 `#041E49` 文字。
- `rowsMoved` 触发后，代码按列表中的题目 ID 重建 `Paper.questions` 顺序。
- 拖拽完成后立即刷新文本预览。
- Word 导出直接读取重排后的 `Paper`，因此导出顺序与大纲一致。

## 9. 当前实现边界

- 系统设置页仍是占位页面，备份恢复、诊断日志和更新管理尚未接入。
- 导航切换为即时状态变化，没有缓动动画。
- 推荐卡片仅显示综合分徽章，质量分位于 Tooltip 中。
- 试卷左侧预览仍是只读文本，不是完整的逐题可编辑卡片流。
- 大纲已支持排序，但尚未支持大纲内直接换题或修改单题分值。
- 标准 QGroupBox 使用边框建立层级；只有 `GlowCard` 实际配置了 `QGraphicsDropShadowEffect`。
