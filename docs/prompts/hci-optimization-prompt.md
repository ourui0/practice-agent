# EduExam Agent 人机交互优化任务书

## 角色

你是一名专精于桌面软件交互设计的 UI 工程师。你将严格基于以下任务清单，逐文件、逐组件地对 EduExam Agent 的 PySide6 前端代码进行审查和改造。每完成一项，在清单中标记结果；发现清单未覆盖但明显违反交互直觉的问题，追加到清单末尾并同样处理。

## 项目背景

EduExam Agent 是面向中小学教师的 Windows 桌面出题工具。教师的核心工作流为：

```
创建课程 → 上传教材(PDF/DOCX) → 自动提取知识点 → 逐题生成/批量组卷 → 导出 Word 试卷
```

当前 UI 技术栈：PySide6 + QSS（Material 3 / Google Workspace 风格），左侧 240px 药丸导航 + 右侧 QStackedWidget 页面区。全局 QSS 及调色板定义在 `src/edu_exam_agent/ui/theme.py`；可复用组件在 `src/edu_exam_agent/ui/widgets.py`；主窗口在 `src/edu_exam_agent/ui/windows/main_window.py`；7 个业务页面在 `src/edu_exam_agent/ui/pages/` 下。

## 全局原则（贯穿所有任务）

- **教师视角**：所有文案以中小学教师的日常用语为准——不说"检索索引/Token/RAG/FTS"，说"搜索教材/配额/基于教材出题/教材原文查找"。
- **即时反馈**：任何耗时 > 0.5 秒的操作，按钮必须变为禁用态 + 进行时文案（如"生成中…"），同时状态栏同步更新。
- **先禁用后校验**：能在按钮上阻止的无效操作，不要等到用户点击后弹 `QMessageBox`。
- **错误三要素**：每个面向用户的错误提示，必须说清 (1) 发生了什么 (2) 原因 (3) 下一步怎么办。禁止裸抛 `str(exc)`。
- **统一基准**：所有页面的外边距、标题样式、按钮文案风格、确认对话框措辞均须一致。
- **不改业务逻辑**：此轮优化仅触及 UI 层（`ui/`）和 `application` 层中直接向 UI 返回错误消息的服务代码。领域模型、数据库 schema、LLM 调用逻辑不动。

## 任务清单

### 1. 页面外边距统一

**现状：** 7 个页面的 `layout.setContentsMargins()` 各不相同——有 `32,26,32,26`、有 `42,34,42,30`、有 `30,24,30,24`。

**任务：** 在 `theme.py` 中定义常量 `PAGE_MARGINS = (32, 28, 32, 28)`，所有页面的根 layout 边距引用该常量。`RecommendationPage` 当前额外的水平留白（42px）改为通过内部 card 的宽度控制实现，不再使用更大的页面边距。

### 2. 统一状态栏（全局上下文条）

**现状：** 每个页面自行维护一个底部 `QLabel`（通常命名为 `self.status`）来显示操作反馈；`MainWindow` 的 `QStatusBar` 仅显示数据目录路径。

**任务：**
- `MainWindow.statusBar()` 改为显示当前工作上下文：`当前课程：{课程名} | 题库 {N} 题 | 教材 {M} 本`。在课程切换时更新。
- 各页面底部的 `self.status` QLabel 保留用于即时操作反馈（如"已生成 3 道题"），但额外定义 `StatusLabel` 组件（放入 `widgets.py`），统一其样式（`#5F6368`、`13px`、最小高度 24px），替换各页面散落的裸 `QLabel`。
- 所有后台线程的开始/结束信号必须在 `statusBar()` 和页面 `StatusLabel` 中同步反映。

### 3. 按钮禁用逻辑补全

**现状：** 部分页面在条件不满足时禁用按钮（如 `SingleQuestionPage` 检查知识点是否已确认），但以下场景缺失前置禁用：

| 页面 | 按钮 | 应禁用的条件 |
|------|------|-------------|
| `MaterialPage` | "上传并解析教材" | 未选择课程 |
| `MaterialPage` | "检索教材原文" | 搜索框为空 |
| `RecommendationPage` | "推荐高分题目" | 未选择课程 |
| `_PaperGenerationPage` | "从题库智能组题" | 所有题型数量均为 0 或未选择课程 |
| `_PaperGenerationPage` | "导出 Word" | 尚未成功组卷（当前已部分实现） |
| `CoursePage` | "编辑"/"复制"/"归档"/"删除" | 未选中任何行 |
| `QuestionBankPage` | "查看详情"/"编辑"/"复制"/"删除"等 | 未选中任何行 |
| `KnowledgePointPage` | "确认选中"/"编辑"/"删除" | 未选中任何行 |

**任务：** 在上述每个页面中，连接 `QTableWidget.itemSelectionChanged` / `QComboBox.currentIndexChanged` / 输入框 `textChanged` 信号到 `_update_button_states()` 方法，在其中统一设置各按钮的 `setEnabled()`。

### 4. 全局键盘快捷键

**现状：** 项目无任何 `QShortcut` 或 `keyPressEvent` 覆盖。

**任务：** 在 `MainWindow` 中注册以下快捷键（使用 `QShortcut`）：

| 快捷键 | 行为 |
|--------|------|
| `Ctrl+1` ~ `Ctrl+7` | 切换到第 1~7 个导航入口 |
| `Ctrl+N` | 触发当前页面的"新建"操作（如无则忽略） |
| `Ctrl+F` | 聚焦当前页面的搜索输入框（如无则忽略） |

在页面内，表格行支持 `Enter` 键触发"编辑/查看详情"（当前 `CoursePage` 通过 `doubleClicked` 已实现双击编辑，`Enter` 应与双击行为一致）。

### 5. 空状态引导

**现状：** 无课程/无教材/无题目时，页面显示空表格 + 底部一行静态提示文字。首次使用的教师不知道该从哪开始。

**任务：** 在每个页面的表格/列表区域之上（或替代空表格）添加空状态引导组件 `EmptyStateWidget`（放入 `widgets.py`），包含：
- 一个语义图标（emoji 或 QPainter 绘制的简笔图标）
- 一句描述当前状态的文字（如"还没有教材，上传第一本教材开始使用"）
- 一个蓝色主按钮直接触发下一步操作（如"上传教材"、"创建课程"）

各页面空状态文案：
| 页面 | 空状态文案 | 引导按钮 |
|------|-----------|---------|
| 教材管理 | 还没有教材，上传第一本教材开始使用 | 上传并解析教材 |
| 智能推荐 | 题库中还没有题目，先生成一些题目再来查看推荐 | 去生成题目 →（跳转到单题生成页） |
| 试卷组装 | 题库中还没有题目，无法组卷 | 去生成题目 → |
| 单题生成 | 当前课程没有已确认的知识点，请先在知识点管理中提取并确认 | 去知识点管理 → |
| 题库 | 题库为空，生成第一道题目 | 去生成题目 → |
| 知识点管理 | 还没有知识点，从教材中自动提取或手动添加 | 从教材提取知识点 |
| 课程管理 | 还没有课程，创建第一个课程 | 新建课程 |

### 6. 表格交互增强

**现状：** 所有表格使用 `SingleSelection`（单选），无右键菜单。

**任务：**
- 所有数据表格改为 `ExtendedSelection`（支持 Ctrl+Click 和 Shift+Click 多选）。
- 工具栏在选中 ≥2 行时，批量操作按钮（"批量删除"等）自动激活；选中 0 行时禁用单行操作按钮。
- 课程管理、题库、知识点管理三个页面的表格添加右键 `QMenu`：
  - 课程管理：编辑、复制、归档/恢复、删除
  - 题库：查看详情、编辑、复制、保留为可用变式、删除
  - 知识点管理：编辑并确认、确认选中、删除
- 表格行高统一为不低于 40px，表头高度统一为 36px。
- 题干类长文本列（题库表格的"题干"列）自动省略：超过 60 字符截断 + "…"，完整文本通过 tooltip 展示。实现方式：在设置 `QTableWidgetItem` 时用 `setToolTip()` 存全文，`setText()` 存截断版本。

### 7. 错误提示重构

**现状：** 大多数错误提示是 `QMessageBox.warning(self, "简短标题", str(exc))`，用户看不懂发生了什么、为什么、怎么解决。

**任务：** 在 `widgets.py` 中添加工具函数：

```python
def show_error(parent, title: str, what: str, why: str, fix: str, detailed: str = "") -> QMessageBox:
    """显示结构化的错误对话框。"""
```

所有现有 `QMessageBox.warning` / `QMessageBox.critical` 调用替换为该函数，按以下映射：

| 当前消息 | what（发生什么） | why（原因） | fix（怎么做） |
|---------|-----------------|------------|--------------|
| "模型未配置" | 无法连接 AI 模型服务 | 尚未添加或配置模型 | 前往「配置与设置 → 模型服务」添加模型 |
| "生成失败" + str(exc) | 题目生成未完成 | 视具体异常而定 | 检查网络连接后重试，或降低难度要求 |
| "缺少课程" | 无法继续操作 | 尚未创建或选择课程 | 先在课程管理中创建课程 |
| "缺少知识点" | 无法生成题目 | 当前课程没有已确认的知识点 | 先在知识点管理中提取并确认知识点 |
| "组题失败" | 无法完成组卷 | 视具体异常而定 | 降低最低综合分要求，或补充题库 |
| "教材导入失败" | {filename} 导入失败 | 文件格式不支持或文件已损坏 | 确认文件为 PDF/DOCX/TXT/Markdown 格式后重试 |

注意：所有 `str(exc)` 的原始异常信息放入 `detailed` 参数（仅在用户点击"查看详情"时展开），不直接展示在主提示文字中。

### 8. 操作可取消

**现状：** 仅教材导入支持取消。单题生成和批量补题发起后无法取消——用户只能等待或强制关闭。

**任务：**
- `SingleQuestionPage`：点击"根据教材生成并检查"后，按钮文字变为"取消生成"，再次点击则调用 `QThread.quit()` / `QThread.terminate()` 并清理 worker。
- `_PaperGenerationPage`：批量补题时，状态区旁边添加"取消补题"按钮，点击后终止 `_batch_thread`。
- 所有线程终止时，在状态栏显示"操作已取消"，并恢复按钮可用状态。

### 9. 删除操作支持撤销

**现状：** 删除后数据直接消失，无法恢复（除课程归档外）。

**任务：** 在 `application` 层添加 `UndoManager`（基于 `deque`，容量 10，有效期 15 秒），记录最近的可撤销操作。UI 层在 `MainWindow` 中监听 `Ctrl+Z`，调用 `UndoManager.undo()`。

首次实现范围：课程删除、题目删除、知识点删除的撤销。删除成功后，状态栏显示"已删除「{名称}」，可按 Ctrl+Z 撤销（15 秒内有效）"。

### 10. 导航与页面切换优化

**现状：** 页面切换为即时跳变，无过渡；侧边栏仅靠按钮的 `active` 属性标记当前页；分组标签"核心功能/资源管理/系统"与教师实际工作流不完全对应。

**任务：**
- 页面切换时，为 `QStackedWidget` 添加 200ms 淡入过渡（使用 `QPropertyAnimation` 作用于 `windowOpacity` 或通过 `QGraphicsOpacityEffect`）。
- 当前选中导航按钮的文字颜色和背景色已有明确区分（好），但需额外在侧边栏中为当前选中项所属的分组标题（`navSection`）加亮——分组标题在所属按钮被选中时变为 `#0B57D0`。
- 导航分组重命名（保持 3 组）：
  - "备课准备"：📚 教材管理、🏷 知识点管理
  - "出题组卷"：✦ 单题生成、💡 智能推荐、📄 试卷组装
  - "资源与设置"：▦ 题库、◇ 课程管理、⚙ 配置与设置
- 同时调整 `NAVIGATION` 元组中入口的顺序和数量（从 7 个变为 7 个，只调整归属和标签），"知识点管理"和"题库"从合并的 Tab 中拆出为独立导航项（删除 `_TabbedPage` 的 `resources` 合并页）。

### 11. 页面内微交互与动画

**现状：** 全应用无任何动画。

**任务（按优先级）：**
1. `GlowCard` 光晕透明度从 0 到可见加 150ms `QTimer` 驱动的渐进过渡（当前立即绘制）。
2. 推荐卡片流在 `refresh()` 后，卡片依次出现——每张卡片延迟 50ms，使用 `QPropertyAnimation` 从透明度 0 渐变到 1。
3. `ChapterPopup` 弹出时做 200ms 的缩放动画（`QPropertyAnimation` 作用于 `geometry`，从按钮位置扩展到目标尺寸）。
4. 表格行在操作成功（如编辑保存、确认知识点）后，对应行背景色短暂变为 `#E6F4EA`（浅绿），500ms 后恢复白色。
5. 删除一行后，该行动画化淡出（200ms 透明度 → 0），再移除。

所有动画时长统一在 `theme.py` 中定义为常量 `ANIMATION_DURATION_FAST = 150`、`ANIMATION_DURATION_NORMAL = 200`、`ANIMATION_DURATION_SLOW = 500`。
